## 한글화 범위

파일·폴더·업로드·공유·보호 키, 할 일, 로그인, 계정 알림과 확인창, 메모 단위, 대화 기본 제목과 역할, 공통 오류·알림·접근성 라벨, 홈·사이드바·테마 그래픽 문구를 한글화했다. Ant Design에도 한국어 locale을 연결했다.

[정적 문자열 목록](localization-inventory.json)은 167개 파일별 변경 항목을 담는다. 이는 유일한 문구 수가 아니며, 동적 문장·개수·그래픽의 조판 변경은 별도로 반영했다. 기존 기본 대화 제목 New Chat은 첫 메시지에 따른 자동 제목 생성 호환 조건에서만 유지한다. 기존 사용자 제목과 내용은 일괄 변경하지 않는다.

공식 명칭 Deepria Cloud·Google·GitHub, AI·Markdown과 키보드 키 이름, 파일 확장자, 사용자 콘텐츠, 코드·API 식별자와 기술 진단 로그는 의미를 보존한다. 사용자 안내에는 한국어를 제공하고 원본 오류는 technicalMessage 등 진단 정보로 구분한다.

`npm run audit:ko`는 Vue 템플릿의 정적 텍스트, UI 속성과 직접 작성한 토스트 문구를 검사한다. CI에도 추가했다. 동적 서버 응답과 사용자 콘텐츠까지 정적 검사만으로 판정하지 않는다.

## 디자인 정리

- A B C와 라이트·다크의 여섯 조합을 유지한다.
- 한국어 시스템 서체 스택을 공통으로 사용한다. 새로운 웹폰트 다운로드 없이 기기 서체를 사용한다.
- 웹의 별꽃 심벌과 기존 PWA 꽃 사진 아이콘은 같은 꽃 모티프의 추상 표현과 개인 이미지로 유지한다. 기존 앱 아이콘을 교체하지 않는다.
- 실제 사용되지 않는 Font Awesome 전역 등록을 제거하고 Ant Design 아이콘과 기존 선형 SVG 체계를 사용한다.
- B의 큰 그래픽을 한국어 조판으로 조정했다. 파일의 모바일 작업 버튼은 별도 행과 44px 영역을 확보했다.
- 테마 변경 시 브라우저 theme-color도 갱신하고 PWA 기본 배경은 A 라이트에 맞췄다.
- 긴 대화, 코드와 표가 포함된 화면을 추가 검수했다. [검사 기록](content-checks.json)

## 재현 방법

기본 검사는 `npm run lint`, `npm run audit:ko`, `npm run test:unit`, `npm run build`다.

브라우저 검증 스크립트는 Puppeteer Core와 Chrome이 준비된 별도 환경에서 실행한다. 프로젝트 실행 의존성으로 브라우저 드라이버를 추가하지 않았다. 모듈이 기본 경로에서 해석되지 않으면 PUPPETEER_MODULE에 모듈의 절대 경로를, Chrome 경로가 다르면 CHROME_PATH를 지정한다.

- 개발 서버를 5175 포트에서 실행한 뒤 `node scripts/verify-workspace.mjs`로 전체 검증을 수행한다. REVIEW_SCOPE=interactions로 상호작용만 재검증할 수 있다.
- 운영 빌드의 preview를 4176 포트에서 실행한 뒤 `node scripts/verify-pwa.mjs`로 서비스 워커를 검사한다. 이 스크립트는 로컬 dist/sw.js에 임시 버전 표시를 붙이고 종료 시 원본으로 복원한다. 운영 주소에는 실행하지 않는다.
- REVIEW_BASE로 로컬 검사 주소를 변경할 수 있다.

## 운영 확인과 남은 검수

작업 중 운영의 루트·메모·대화 직접 진입은 200 text/html, manifest는 application/manifest+json, 서비스 워커는 text/javascript 응답을 확인했다. 이 시점은 새 구현을 push하기 전이므로 새 버전의 배포 완료 근거로 사용하지 않는다.

배포 후에는 build-info.json의 commit을 원격 main과 비교하고 dirty가 false인지 확인한다. JSON 대신 SPA HTML을 반환하면 호스팅 rewrite에서 정적 JSON 경로를 확인한다. 버전 확인과 별개로 인증·파일·대화·PWA를 실제 환경에서 검수한다.

운영 반영 후 build-info.json에서 구현 커밋 255379a와 dirty false를 확인했다. 실제 서비스의 한글 로그인 화면과 비로그인 메모 직접 진입의 로그인 복귀도 확인했다. [운영 확인 기록](deployment-checks.json)

남은 항목은 실제 Android Chrome·Samsung Internet·iOS Safari, 물리 키보드와 가상 키보드·스크린 리더·브라우저 200% 확대, 실제 OAuth와 파일 전송, 실제 설치형 PWA의 운영 캐시 전환과 복구 절차 실행 검증이다.

복구가 필요하면 255379a 적용 전 main인 e96295c를 기준으로 새 구현을 revert하고 검증 후 배포한다. 원격 기록을 강제로 되돌리지 않는다. 기존 최초 백업은 로컬 codex/backup-main-20261029에 유지한다. 운영 복구를 실제로 실행하지는 않았다.
